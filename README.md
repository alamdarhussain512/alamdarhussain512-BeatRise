# BeatRise - Starter Scaffold

This repository contains the starter scaffold for BeatRise — a music career simulation game (Android).

This initial commit contains script stubs, README, and license notes for free assets. The full Unity project (scenes, assets) will be added in following commits. For now these files let you review initial code structure and get started.

Recommended Unity version: Unity 2022.3 LTS
Android target: API 29 (Android 10)

Package name (default): com.alamdarhussain512.beatrise

What I pushed in this commit:
- Initial README (this file)
- .gitignore for Unity
- Script stubs under Assets/Scripts/
- assets_licenses.txt with links to free assets

Next steps (what I'll do next):
- Add scene files and minimal UI prefabs
- Add Addressables config and small free asset pack (Kenney UI + 1-2 music loops)
- Provide APK for testing

How you can help:

- If you want the code on the default branch instead, tell me and I'll move/merge it.
